# Modelo de guia de escrita de produto

## Índice
1. Como usar
2. Modelo

## 1. Como usar
Para um produto que ainda não tem guia. Preencha a partir dos materiais que existirem (site, telas atuais, documentos de marca) e do que a Julia disser. O que não se sabe fica como PENDENTE. Salve como `references/produtos/<produto>.md` na skill e acrescente o produto na seção 2 do `SKILL.md`.

## 2. Modelo

````markdown
# Guia de escrita: <produto>

## Fontes
<documentos usados, com data>

## Para quem escrevemos
<público principal, contexto de uso, nível técnico>

## Voz
| Somos | Não somos |
|---|---|
| <ex.: direto> | <ex.: seco> |

## Tom por situação
| Situação | Tom | Exemplo |
|---|---|---|
| Erro | | |
| Sucesso | | |
| Primeiro uso | | |
| Ação irreversível | | |

## Regras de forma
- Maiúsculas: <…>
- Pontuação em títulos e botões: <…>
- Datas, horários, números, moeda: <…>
- Tratamento (você, tu, nome): <…>
- Linguagem neutra: <…>

## Termos
| Use | Não use | Observação |
|---|---|---|

## Pendências
- <decisão que precisa de alguém do produto>
````
