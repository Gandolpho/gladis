# Modelo de plano de entrega (até 5 dias)

## Índice
1. Como usar
2. Modelo

## 1. Como usar
Para entregas de hoje a 5 dias. Vai na nota de entrada do projeto ou no chat; cada dia vira tarefa em `02 ✅ Tarefas/`. Só o primeiro dia aparece em ações.

## 2. Modelo

```markdown
## Plano: <o que precisa estar pronto>
Prazo: <dia, data> · Para: <quem recebe> · Depende de: <ninguém / PO / design lead / dev>

| Dia | Marco (pronto no fim do dia) | Essencial? |
|---|---|---|
| <seg> | <…> | sim |
| <ter> | <…> | sim |
| <qua> | Folga para ajustes e imprevistos | |

**Hoje:**
- [ ] <primeiro passo de 2 min>
- [ ] <passo>
- [ ] <passo>

**Se apertar:** <o que corta ou negocia primeiro>
```
