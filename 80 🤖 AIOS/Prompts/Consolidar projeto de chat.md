# Consolidar projeto de chat

Cole na conversa do projeto (Claude ou ChatGPT) e salve a resposta em `00 📥 Inbox`.

```
Consolide tudo o que conversamos neste projeto em um único documento Markdown: contexto, problema, usuário, decisões tomadas (com data), regras de design, pendências, tarefas e próximos passos. Marque cada informação como Confirmado, Hipótese ou Pendente. Não invente o que não foi dito.
```
